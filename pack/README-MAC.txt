MIX TIP BOT — Logic pack for Mac
================================

This is NOT a VST. Logic Pro does not load VST or VST3.
The Unarchiver only unzips this folder. It does not install a plugin.

WHAT IS IN HERE
---------------
README-MAC.txt     this file
INSTALL.command    copies files and opens the script
TIP-Scripter.js    paste into Logic MIDI FX → Scripter
TIPS.txt           same tips offline

INSTALL
-------
1. Open the zip with The Unarchiver.
2. Double-click INSTALL.command.
   If macOS blocks it: Right-click → Open.
3. A folder appears on your Desktop and in Music/Sound Tip of the Day.
4. In Logic:
   MIDI FX → Scripter → Open Script Editor
   Paste TIP-Scripter.js → Run Script
   Save As: MIX TIP BOT

The .js copied into Plug-In Settings/Scripter will NOT show in the preset menu.
Logic only lists .pst files it saved itself.

DO NOT drop this folder in Library/Audio/Plug-Ins/Components.
DO NOT rename this to .vst3 or .component.
