## Mac pack (Logic, not a VST)

Download the whole repo zip:
https://github.com/youngsegaaudio-gif/vocal-source/archive/refs/heads/main.zip

1. Open the zip with The Unarchiver. Unarchiver only unzips. It does not install a plugin.
2. Open the `pack` folder.
3. Double-click `INSTALL.command`.
4. In Logic: MIDI FX → Scripter → paste `TIP-Scripter.js` → Run Script → Save As **MIX TIP BOT**.

This is a Logic MIDI FX Scripter + a Safari page. Logic does not load VST. A website cannot scan your whole Mac. The tip page only reads filenames you pick.

## Turn Pages on (one click)

1. Open https://github.com/youngsegaaudio-gif/vocal-source/settings/pages
2. Source: **GitHub Actions** (or Deploy from branch **main** / **/ root**)
3. Save. HTTPS is automatic.

No audio. No lyrics. You source and clear what you sample.
